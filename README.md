# AX YOUR BODY prototype
Open index.html or publish the contents of this folder using GitHub Pages (main / root). No build step.
Original source: user-provided Google Stitch ZIP, eight HTML screens. Added relative navigation and prototype.js. Internet required for original Tailwind CDN, fonts and remote images. Remote asset availability not verified. Demo only: local storage, sample data, simulated workout countdown, no backend, actual video, audio or AI recommendation. Sunday scenario switch added for demonstration. Workout steps reuse original illustration/instructions. Browser runtime not tested.
GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
